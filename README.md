# App Hotel — Agenda 13 (ETEC)

Projeto didático em C# e .NET MAUI com telas **Reservar** e **Sobre**.

- Desenvolvedor: Théo Henrique
- Ano: 2026
- Componentes: DatePicker, Picker, Stepper e BindingContext
- Plataforma deste pacote: **Windows** (Visual Studio 2026 / .NET 10)

## Como abrir
1. Extraia este ZIP em uma pasta nova (não misture com a versão antiga).
2. Abra `AppHotel_Agenda13.csproj` no Visual Studio.
3. Selecione `Windows Machine` como destino de execução.
4. Execute com F5. Clique na aba **Sobre**.
5. Tire capturas reais da tela Sobre (Win + Shift + S) e salve na pasta `Screenshots`.
6. Comprima a pasta `Screenshots` e entregue com o link do repositório GitHub.

**Importante:** este projeto foi preparado a partir dos conceitos da apostila e da primeira versão do projeto, mas **não foi compilado nem executado neste ambiente**. Se o Visual Studio apresentar erro, copie a primeira mensagem da Lista de Erros. O código do repositório de referência do professor não foi incorporado, porque não foi possível baixar o repositório aqui.
